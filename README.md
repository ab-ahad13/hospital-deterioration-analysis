# Hospital Deterioration Analysis

## Project Overview

This project analyzes hospital patient data to identify patterns related to patient deterioration.

The dataset was cleaned and processed using Python. Basic preprocessing techniques were applied to prepare the data for analysis.

## Objectives

- Clean raw hospital data
- Process patient records
- Prepare data for analysis
- Explore patient deterioration patterns

## Tools Used

- Python
- Pandas
- Microsoft Excel
